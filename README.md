# Web 灵感弹药库（Web Arsenal）

> 把「看到的好效果」，变成「能跑、能调、能直接喂给 AI」的弹药。
> **67 条零依赖网页动效 / 交互素材 + 19 套整站换肤方案**，每条配可运行 Demo +
> 可调参数 + 大白话说明 + 完整可复刻的 AI 提示词。

## 这是什么

一个面向「用 AI 辅助做网页的人」的素材库（vibe coding 弹药箱）。它和普通收藏夹、
灵感站的区别是：**效果即代码**——看到的东西不只是截图和文字，而是一条能直接跑、
能调参、能复制给别人用的成品弹药。

- **效果即代码**：每条素材都是 `assets/demos/` 里可直接双击运行的原生 HTML/CSS/JS，
  零框架、零 CDN、可离线
- **小白词检索**：标签不说黑话（「手机端网页」「鼠标悬停」），按
  文字动画 / 背景 / 动效 / 组件 / 布局骨架 五大分类组织（整站方案已独立成「方案库」视图）
- **提示词直达**：每条配一段完整提示词（效果 + 用法示例 + 关键参数 + 集成步骤），
  复制给 AI 就能照做
- **参数联动**：滑杆 / 开关 / 取色器调完之后，复制出来的提示词和代码就是你调好的
  那一版，不存在「演示调过、复制出来还是默认值」的错位

## 为什么做（先读：这不是抄袭）

做这个库的动机是**学习拆解 + 复用沉淀**：把在好网站上看到、在项目里用过的交互手法，
用自己的理解重写一遍、讲清楚、存下来，下次做网页直接取用。它不是素材的搬运，而是
「看到 → 拆解 → 复刻 → 沉淀」的完整消化过程。

### 来源与原创声明

- 本库 **67 条素材逐条标注「来源 + 分析日期」**，字段就写在 `data/素材.js` 里，可追溯
- 本库所有代码均为**观察交互手法后的原创复刻 / 自写**，原生 HTML/CSS/JS 零依赖重写，
  未复制任何网站源码、字体、图片或商业素材
- 借鉴对象包括：ReactBits（MIT 许可，已逐条标注）、Stripe / Apple / stateofaidesign
  等官网的交互手法，以及视频资料中的通用交互模式
- 网页的「交互思路 / 动效手法」属于通用设计语言；本库展示的是自己的实现，不是
  别人的代码或设计资产
- 如果你认为某条内容涉及你的作品且不妥：提一个 Issue 说明，确认后立即下架

## 快速开始

```text
双击 index.html      # 画廊直接开，素材卡内嵌降级版 Demo 可离线跑（见下方说明）
```

关于本地服务器：画廊卡片默认加载的是「降级版」Demo（2D / Canvas，file:// 直接可跑，离线可用）。
只有完整版（粒子星系 ThreeJS 版、星流 Astra 完整版）用到 ES module（`<script type="module">` + import），
浏览器禁止 file:// 下加载本地模块，需起本地服务器才能看完整 3D：
```
cd 项目目录 && python -m http.server 8000   # 然后浏览器开 http://localhost:8000
```
在线演示（GitHub Pages）正在部署。

## 给 AI 客户端用：本地 MCP（可选）

`mcp/` 是一个 stdio MCP 服务器，让 Cursor / VS Code / WorkBuddy 等 MCP 客户端能直接
搜索、读取弹药库素材（ReactBits 也提供同类 MCP 能力）。启用方式：

```text
cd mcp && npm install        # 安装 @modelcontextprotocol/sdk
node server.js               # MCP 客户端把该命令配成 stdio 服务器即可
```

提供 5 个工具：`search_materials`（多维筛选）、`get_material`（完整条目）、
`get_prompt`（只取提示词）、`get_code`（只取可运行 HTML）、`random_material`（找灵感）。

## FAQ

**可以直接抄走用吗？** 可以。代码部分按 MIT 许可自由使用（商用也行），保留版权声明即可；
不要把仓库里的效果说成完全原创的设计即可。

**这些效果是从大网站「扒」来的吗？** 不是。只借鉴交互手法，代码全部自写重写，逐条标注
来源；不复制任何第三方源码、字体、图片或商业素材，详见上方「来源与原创声明」。

**为什么每条素材要配一段「给 AI 的提示词」？** 因为 AI 辅助开发已经成为做网页的主流
工作流。效果 + 关键参数 + 集成步骤写清楚，复制给 AI 就能复刻出同款效果，省去从零描述。

**想提交素材 / 报问题？** 提 Issue 或按 `01-素材条目模板.md` 的标准补充素材。
