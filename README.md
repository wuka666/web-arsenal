# Web 灵感弹药库（Web Arsenal）

> 把「看到的好效果」，变成「能跑、能调、能直接喂给 AI」的弹药。
> **92 条素材（85 条网页动效/交互素材 + 7 条 AI 反馈示意）+ 20 套整站换肤方案**，每条配可运行 Demo +
> 可调参数 + 大白话说明 + 完整可复刻的 AI 提示词。

## 这是什么

一个面向「用 AI 辅助做网页的人」的素材库（vibe coding 弹药箱）。它和普通收藏夹、
灵感站的区别是：**效果即代码**——看到的东西不只是截图和文字，而是一条能直接跑、
能调参、能复制给别人用的成品弹药。

- **效果即代码**：每条素材都是 `assets/demos/` 里可直接双击运行的原生 HTML/CSS/JS，
  零框架、零 CDN、可离线
- **小白词检索**：标签不说黑话（「手机端网页」「鼠标悬停」），按
  文字动画 / 背景 / 动效 / 组件 / 布局骨架 / AI反馈 六大分类组织（整站方案已独立成「方案库」视图）
- **提示词直达**：每条配一段完整提示词（效果 + 用法示例 + 关键参数 + 集成步骤），
  复制给 AI 就能照做
- **参数联动**：滑杆 / 开关 / 取色器调完之后，复制出来的提示词和代码就是你调好的
  那一版，不存在「演示调过、复制出来还是默认值」的错位
- **画布组装**：右下角悬浮按钮打开全屏画布，素材先按类型自动归位，再**自由拖拽拼接**成一张网页
  （拖标题栏移动、拖右下角调大小、四角拉伸画布），点中任意素材可单独调它的参数 —— 库是「挑」，画布是「做」

## 为什么做（先读：这不是抄袭）

做这个库的动机是**学习拆解 + 复用沉淀**：把在好网站上看到、在项目里用过的交互手法，
用自己的理解重写一遍、讲清楚、存下来，下次做网页直接取用。它不是素材的搬运，而是
「看到 → 拆解 → 复刻 → 沉淀」的完整消化过程。

## 快速开始

```text
双击 index.html      # 画廊直接开，素材卡内嵌降级版 Demo 可离线跑（见下方说明）
```

关于本地服务器：画廊卡片默认加载的是「降级版」Demo（2D / Canvas，file:// 直接可跑，离线可用）。
只有完整版（粒子星系 ThreeJS 版、星流 Astra 完整版）用到 ES module（`<script type="module">` + import），
浏览器禁止 file:// 下加载本地模块，需起本地服务器才能看完整 3D：
```
cd 项目目录 && python -m http.server 8000   # 然后浏览器开 http://localhost:8000
```
在线演示（GitHub Pages）正在部署。

浏览器要求：建议 Chrome / Edge 111+、Safari 16.2+、Firefox 113+。库里有 26 个 demo 用到
`color-mix()`（Chrome 111 起支持），更旧的浏览器会掉一部分配色；其余用到的特性
（`aspect-ratio`、`backdrop-filter`）门槛更低。

## 画布（把素材组装成一页）

「画布」和素材库 / 方案库是两回事 —— **库是用来「挑」的，画布是用来「做」的**。
入口是页面右下角的**悬浮按钮**：按住可拖到任意位置，右下角小把手可调按钮大小，点一下弹出全屏白底画布；
画布面板的四个角都可以像调浏览器窗口一样拉伸（尺寸会记住），**双击标题栏**在最大化 / 还原间切换。

### 它怎么工作

每个素材本身就带语义标注（`分类` + `子类`），画布拿这个当**角色**，给新加进来的素材一个合理的起点位置：

| 角色 | 判定依据 | 自动落在 | 库里对应什么 |
|---|---|---|---|
| **背景 · 铺满** | `分类 = 背景` | 铺满整个画布、垫底 | 粒子星系、细雨、绸缎渐变、3D 背景（10 条） |
| **导航 · 贴顶** | `子类 = 导航` | 顶部通栏 | 侧边栏导航、汉堡菜单导航、面包屑导航（10 条） |
| **首屏** | `子类 = 首屏Hero` | 导航之后 | 英雄区大字号排版、光标探照揭示 Hero（2 条） |
| **内容流** | 其余 | 主体区双列交错 | 粒子文字、数字滚动、卡片翻面… |
| **浮层 · 悬浮** | `子类 = 弹窗抽屉 / 提示条` | 右下角悬浮 | 底部抽屉、嵌套抽屉、更新公告胶囊（8 条） |

自动归位只是**起点**，之后完全自由：

1. **无限画布**：拖画布空白处平移视角，**Ctrl/⌘ + 滚轮**以鼠标为中心缩放（右下角有 −/＋/适应/1:1 工具条，
   「适应」一键缩放到正好看到全部素材）；相机状态也会记住
2. **拖任意块的标题栏** → 摆到画布任意位置；**拖右下角** → 调整块大小；
   也可以把素材**从左栏候选直接拖进画布**，落在松手的位置。
   块内演示按灵感库站点的通用做法渲染：固定设计尺寸 + 等比缩放裁切（`object-fit: cover`），永不拉伸变形；
   **背景块永远自动铺满当前可视区**（平移缩放都跟着盖满，像真网页的 body 背景）
3. **点标题栏选中**某块 → 右侧面板立刻切出**这个素材自己的参数**（滑杆 / 取色器，实时生效），
   和「统一主题」并存 —— 主题管全局，私人参数只管选中块且优先级更高
4. `换层` = 换个自动落位；`☆` 存购物车；`×` 移除；「**一键整理**」全部回到自动归位
5. 「用购物车生成」= 已选素材一次铺开；「全部存入购物车」= 反向收齐
6. **统一主题**：主色 / 重点色 / 页面底色 / 圆角 / 基础字号 / 阴影 / 发光 —— 改一处全部一起变
   （按「参数键名或中文名」自动匹配各素材，没有对应参数的自动跳过）
7. 提示词**不占页面**：点面板头部的「复制提示词」，生成的是**按实际坐标描述**的结构化提示词
   （每块的位置 / 大小 / 所属层 + 统一主题 + 各素材完整提示词与当前参数），直接粘给 AI
8. 画布、按钮位置、面板尺寸全存 `localStorage`，刷新不丢；「清空画布」不影响购物车

### 为什么提示词按坐标写

AI 拿到「一列素材清单」时，最容易把导航排到内容后面、把背景当普通区块。画布把你**摆好的位置**
（百分比坐标、大小、铺满 / 贴顶 / 悬浮等语义）显式写进提示词，还原度会稳得多。

这个做法参考了 `lnkiai/m3e-canvas`（MIT）——它有个 `lib/tidy.ts` 规则布局引擎，靠组件类型（`isTop` / `isBottomBar` / `isFab` / `isOverlay` / `isRail`）决定每个组件的落点，注释里写着 *"Nothing here is guessed by a model."* 本库借的是这套**「语义 → 位置」的规则**，代码全部自写、不引任何依赖。

## 给 AI 客户端用：本地 MCP（可选）

`mcp/` 是一个 stdio MCP 服务器，让 Cursor / VS Code / WorkBuddy 等 MCP 客户端能直接
搜索、读取弹药库素材（ReactBits 也提供同类 MCP 能力）。启用方式：

```text
cd mcp && npm install        # 安装 @modelcontextprotocol/sdk
node server.js               # MCP 客户端把该命令配成 stdio 服务器即可
```

提供 5 个工具：`search_materials`（多维筛选）、`get_material`（完整条目）、
`get_prompt`（只取提示词）、`get_code`（只取可运行 HTML）、`random_material`（找灵感）。

来源；不复制任何第三方源码、字体、图片或商业素材，详见上方「来源与原创声明」。
