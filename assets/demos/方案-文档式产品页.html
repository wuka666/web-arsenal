快速开始 / 初始化

初始化客户端

用一行配置把 SDK 接入你的项目。文档即产品首页——开发者读到这里就已经在用起来了。

安装

# 使用你习惯的包管理器 npm install @quill/sdk

初始化

引入客户端并传入项目令牌，SDK 会自动拉取默认配置。

import { Quill } from '@quill/sdk'; const client = new Quill({ token: process.env.QUILL_TOKEN, region: 'ap-chongqing' });
◆令牌只应在服务端读取，切勿写入前端打包产物——此处仅为文档示意。

下一步

完成初始化后，继续阅读「鉴权」了解如何为用户签发短期凭证，或直接进入「SDK 参考」查看全部方法。
