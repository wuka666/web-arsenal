视图
滚轮以鼠标位置为中心缩放（8%–300%）
+ / −放大 / 缩小
0缩放到 100%
f适应窗口
空格 + 拖动平移画布（也可直接拖画布外空白）
组件
Delete删除选中组件（Backspace 同效）
Ctrl/⌘+D原地复制选中组件（右下偏移 16px）
Ctrl/⌘+C / V复制 / 粘贴组件（可跨屏幕粘贴）
←→↑↓微移 1px；加 Shift 微移 8px
拖四角手柄改组件宽高
双击组件文字画布上直接改（单行文字）：Enter 提交 / Esc 取消 / 点别处提交
双击正文 / 列表 / 素材多行文字、列表项、动效参数 → 跳到右侧检查器对应输入框

Ctrl/⌘+S立即保存到本机（不触发浏览器「另存为网页」）

Ctrl/⌘+Z撤销（输入框里则是输入框自己的撤销）
