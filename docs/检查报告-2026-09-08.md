### 1. `index.html` 里 `copyText` 被重复定义，后者覆盖前者

同一个 `<script>` 作用域（379–1125 行）里有两个同名函数，**签名相反**：


### 4. s209「粒子星系」参数联动断链

违反 **规矩 10④**：「用户调了参数后，提示词末尾要带当前参数、代码里的 `state` 要替换成当前值，不许错位」

**断点 1 — 代码注入失效**：

```js
// index.html:796
function buildCode(it, current) {
  let code = it.代码 || "";
  if (code.includes("const state")) {          // ← s209 的代码字段没有 const state
    code = code.replace(/const state = \{[\s\S]*?\};/, ...);
  }
  return code;                                  // 原样返回，永远是默认值
}
```

s209 的代码用的是 `createAstraScene(canvas, { flowSpeed: 0.8, ... })` 内联对象，没有 `const state` → 全库 67 条里**唯一**一条注入失败的。

**断点 2 — 提示词数值自相矛盾**：

s209 的 `提示词` 结尾硬编码了一行：

```
当前参数：starCount=4000, size=2.05, scatter=0.041, palette=astra, ...
```

而 `buildPrompt()` 又会无条件追加：

```
—— 你当前的参数设置（照这个给 AI）——
- 星数 = 6000
- 星星大小 = 1.2
```

用户调完参数复制出去，提示词里同时存在「4000」和「6000」两套数字，给 AI 的指令直接打架。全库 67 条里**唯一**一条硬编码「当前参数」的。

**⚠️ 这条要给 trae 记个功**：s209 的 14 个参数键与 `粒子星系-ThreeJS.html` 的 `state` **完全一一对齐**（starCount / size / scatter / backgroundRatio / rotationDepth / palette / bloomIntensity / bloomThreshold / intensity / flare / ambientColor / vignette / flowSpeed / twinkleSpeed），且 ThreeJS 版的 postMessage 处理写得很对（形状类参数重建场景、外观类参数走 setConfig）：

```js
if (['starCount','scatter','backgroundRatio','rotationDepth','palette'].includes(d.key)) {
  if (astra) { astra.dispose(); init() }        // 需重建
} else if (astra) { astra.setConfig?.({ [d.key]: d.value }) }   // 热更新
```

参数设计本身是对的，符合 规矩 11②「参数给完整版」。坏的只是联动链路那两处。

## 七、需要你拍板的 3 个问题

### A. 规矩 5 的「说明」标准已和实操漂移，全库 0 条符合字面要求

**宪法原文（规矩 5）**：
> **我的说明**（好在哪——用三把尺子 / 构图笔记的语言 + 能怎么改）…… 说明**没写满两行**、没有可运行演示的不入库

**实际字段结构**（67 条统一）：
```
效果说明: "从一个页面切到另一个时，旧页面先滑走、新页面再滑进来，不会突然「啪」地换页。"   ← 一句小白话
用法:     "……"                                                                      ← 另一个字段
```

字段名是 `效果说明`（不是 `说明`），内容是**小白中文描述效果**，不是三把尺子术语，也不含「能怎么改」。最短的 4 条：w003 (38字) / w004 (38字) / a103 (36字) / s202 (34字)，都是单句。

**这个漂移是刻意的还是失控的？** 两条路：
1. 改宪法：把 规矩 5 的说明标准改成「效果说明（小白中文一句话）+ 用法（怎么改）」，对齐现状
2. 改数据：67 条全部补三把尺子语言 + 能怎么改，凑满两行

我倾向 1（现状的小白中文其实更符合「自用检索」场景，三把尺子术语反而增加自己看的成本），但这是宪法条款，按 规矩 3 + 五、修订机制，得你确认。

### B. 规矩 5 / 3.3红线 与 规矩 10③ 内部冲突，s209 正好卡在中间

| 出处 | 原文 | 对 s209 的判定 |
|---|---|---|
| 规矩 5 | 代码（可复制 / **库引用**） | 合规 ✓ |
| 3.3 设计红线 | 复杂代码库化（`assets/库/`），**复制一行引用 + 用法即可** | 合规 ✓ |
| 规矩 10③ | 代码必须是完整可运行的源码（**不是一句文件引用**） | **违规 ✗** |

s209 的代码字段 = `import { createAstraScene } from './starflow.js'` + 集成片段（1039 字）。三条规矩给出三种判定。

**哪条优先？** 建议在 规矩 10③ 加个例外条款：「引用 `assets/库/` 内自有库文件的，视为完整代码，但必须同时给出下载入口」——这样和 规矩 11④（3D 类素材提供下载按钮）也咬得上。
